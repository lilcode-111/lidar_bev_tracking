# 15.4 Phase-1 Day4: release gates and candidate selection

Day4 is the final implementation day of Phase-1. It freezes Gate 0 through
Gate G, offline-recomputable gate evidence, baseline-zero delta semantics,
Pareto selection, performance-equivalent tie-breaking, and the fixed
non-Pareto/non-equivalent lexicographic branch.

Only T1 and T2 can become release candidates. T0 remains the safe baseline and
T_off receives full diagnostics but is permanently excluded from selection.
All gates are non-compensatory. A failed Gate 0 prevents interpretation of all
later gates.

The formal artifact uses schema
`15.4-intensity-filter-ablation-v1`. Its Phase-1 skeleton contains no formal
results and marks every variant `NOT_RUN`.

Day4 does not authorize a formal run by itself. After tests pass, commit the
entire Phase-1 materialization, confirm a clean tree, and freeze that commit as
the formal comparison commit. The post-commit authorization record must bind
the schedule hash, release-gate hash, materialized T0 references, and commit
before Phase-2 can start.
