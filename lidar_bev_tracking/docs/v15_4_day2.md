# 15.4 Phase-1 Day2: T0 reference and replay contracts

Day2 adds diagnostic identity fields and a T0-only materialization command. It
does not run T1, T2, or T_off and does not authorize the formal comparison.

The T0 materializer runs the frozen 100-frame manifest once. From that single
run it builds the full 100-frame identity reference and the delta-22 25-frame
point-index reference. O3 counts and IoU must reproduce the frozen 15.3.2
artifact before the reference is written.

The 100-frame geometry-sanity summary is retained as a non-blocking diagnostic.
It is not part of the frozen 15.4 T0 replay gate; manifest completeness,
identity evidence, O3 reproduction, and historical TP/FP/FN reproduction remain
blocking. The raw materialization report is written before those reference
checks so a failed validation does not discard the diagnostic evidence.

The source-point monotonicity validator compares `(frame_id,
raw_lidar_point_index)` sets. It never deduplicates by coordinates.

Unit tests use synthetic fixtures only:

```bash
PYTHONPATH=src python -m unittest tests.test_v15_4_materialization_day2 -v
```

After tests pass, materialize T0 only:

```bash
PYTHONPATH=src python scripts/materialize_v15_4_t0_references.py
```

The generated index intentionally keeps `formal_run_authorized=false` until
the reference hashes are reviewed and frozen.
